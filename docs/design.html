video-cut-agent · Design Language

剪辑工坊.

语义驱动的智能剪辑与引导型动效编排工作流。我们的动效不是炫技的特效，而是科普视频里那些把视线带到该看的地方的东西——圈选、关键词卡、结构图、解释插画。这份设计语言定义了它们长什么样、按什么规则出现。

01五类动效元素

所有动效收敛为五类可编排的事件，由时间轴 JSON 契约驱动。执行器只认契约，不认视频。

OVERLAY

引导标注

叠加在画面上，把视线带到关键位置。

圈选 · 箭头 · 高亮 · 局部放大
CARD

关键词信息卡

把抽象名词落成字幕条、术语卡，停留可读。

字幕条 · 术语卡 · 标签
DIAGRAM

结构可视化

把关系画出来：思维导图、流程图、数据图。

思维导图 · 流程图 · 数据图表
ILLUSTRATION

解释型插画

用户没见过的东西，做成示意图展示出来。

概念示意 · 剖面 · 科普插画
ANIM

程序化动画

场景级代码动画，由同一函数计算帧，天然连贯。

代码即视频 · 场景动画 · 数据驱动

02风格基调预览

制作前由人选风格预设，锁定后注入审美指导文件。当前两套候选基调（示意：仅表达视觉方向，不含实际文案）。

暖纸编辑风

米白纸张 + 暖褐编辑标注，像知识区编辑台的工作台面。温暖、克制、阅读舒适，适合人文向科普与轻叙事。

● 候选基调 A

深空科技风

深空渐变 + 冷白/青色高亮，精密网格与克制的辉光。冷静、清晰、宇宙感，适合科技向科普与数据解释。

● 候选基调 B

03三层质量保障

质感不是靠玄学提示词，而是靠结构化的三层保障——下限、方向、目标。

LAYER 1

组件库

预置设计良好的组件与风格预设，决定"地板"——默认不可能丑。社区预设（video-shotcraft 214 风格 / HyperFrames 模板）带效果图对标。

LAYER 2

审美指导

aesthetic-guide.json：色板、字体、特效、风格的方向与限制。人审驳回理由经确认后沉淀为约束，只增不减。

LAYER 3

参考素材

每次制作前选定参考目标，让动效有明确的对齐对象，而不是凭空发挥。

04设计原则

动效出现的纪律，比动效本身更重要。

  • 引导而非装饰——每个动效必须回答"帮用户看到什么"；纯粹好看的动效不进时间轴。
  • 解释而非炫技——抽象概念配结构图，陌生事物配插画；特效服务于理解，不服务于存在感。
  • 克制与一致——同一内容同类信息用同一组件；颜色只承担分组、状态与重点，不承担装饰。
  • 人审校准——机检只查"基础内容没做好"，审美判断永远留给审核层，驳回理由沉淀回约束。
  • 语义锚点驱动——一切动效锚定在语义上（词、句、概念），绝对时间只是派生缓存。
风格预设库规划：style-presets.json（id / name / source / palette / typography / motion_language / preview / constraints）。 来源对标 video-shotcraft（镜头配方 + 运动语言）与 HyperFrames（模板带视频 demo）；制作前由人选定基调。
