# ADR-0001 · 四层架构定稿（编排/执行/机检/审核）+ 人在回路半闭合

## 上下文

企划"AI 视频剪辑工作流"：输入原始视频 + 转录，自动完成粗剪与动效编排，目标出片。经 motion-reel 调研与概念对齐（动效 = 引导型叠加 + 解释型生成两类），确认多模块拼凑可行、编排是核心；整个工作流是一个闭合 Agent。

## 决策

1. **四层架构**：编排层（任务拆解→时间轴 JSON）· 执行层（多执行器，统一接口）· 机检层（只查硬指标，规则化）· 审核层（人查验校准，不制作）。
2. **内核**：状态机循环（pending→planned→executing→checking→reviewing→done + redoing/stuck），重做预算默认 3 次，生成型事件占位后回填。
3. **人在回路半闭合**：机检全自动，人只做最终校准（批准/驳回/改参数），人不参与制作。
4. **契约先行**：时间轴 JSON 是全流程唯一契约，schema 先定稿、模块后接入。

## 理由

- 依理念 §1（四层边界铁律）、§2（契约先行）、§3（模块可替换）、§4（机检窄边界）、§5（决策层+契约层是护城河）。
- 机检窄边界来自用户拍板："Agent 自验收基础内容质量，容易实现；审美由人判断"——避免机检假装懂审美（参考 motion-reel：技术有效 ≠ 视觉接受 ≠ 观众反馈）。
- 人在回路：人的成本只在最终判断，不消耗在制作上，是全流程效率的关键设计。

## 后果

- 正向：执行器全部可替换；换工具不改编排；机检实现成本低；人审 30 秒校准可支撑批量。
- 负向/待观察：锚点检测（实拍对象定位）是全流程唯一需要真视觉模型的难点，需独立子模块验证；生成型事件（illustration/anim）耗时决定单条视频吞吐上限。
