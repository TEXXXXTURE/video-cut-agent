## 0. 架构总览（定稿，v0.1 继承）

```mermaid
flowchart LR
    IN[输入：原始视频 + 需求 + 转录文本] --> ORCH[① 编排层<br/>任务拆解 → 时间轴JSON]
    ORCH --> EXEC[② 执行层<br/>粗剪 + 五类动效执行器]
    EXEC --> CHECK[③ 机检层<br/>基础质量自动验收]
    CHECK -->|不通过·重做预算-1| EXEC
    CHECK -->|通过| REVIEW[④ 审核层·人<br/>查验校准·不制作]
    REVIEW -->|驳回·带原因| EXEC
    REVIEW -->|批准| OUT[输出：成片 + 时间轴JSON + 产物清单]
```

**四层职责一句话**

| 层 | 一句话 | 谁做 |
|---|---|---|
| ① 编排层 | 把"做出成片"拆成步骤序列，输出唯一契约产物：时间轴 JSON | AI（LLM + 规则） |
| ② 执行层 | 按事件调对应模块干活，吐产物 + 元数据 | 多执行器（自建 + 现成工具） |
| ③ 机检层 | 只查"硬"指标：没做错（锚点/时长/一致性/编码） | AI（规则 + 工具校验，不做审美判断） |
| ④ 审核层 | 只判"做得好不好"：批准 / 驳回 / 改参数 | 人 |

**关键术语（v0.2 增补）**

| 术语 | 定义 |
|---|---|
| 事件（event） | 时间轴 JSON 里一个最小动效单元，五类：overlay / card / diagram / illustration / anim |
| 语义组（group） | 一个讲解要点 = 一组事件，共享锚点/主题 |
| **语义锚点（semantic anchor）** | 事件/字幕的主键，锚到某句/某词（segment/word id）；剪辑重剪后不失效 |
| **派生秒（derived seconds）** | start/end 只是从语义锚点派生的缓存，剪辑/重映射时重算，不作主键 |
| 时间轴 JSON | 编排层唯一输出，全流程契约 |
| 执行器（executor） | 吃事件、吐产物+元数据的模块；统一接口，可替换 |
| 重做预算 | 每个事件允许重做的次数上限，耗尽则上报人工接管 |
| 内核 | 驱动全流程的状态机循环 |

## 1. 内核：工作循环状态机（v0.1 继承，无变更）

### 1.1 状态定义

| 状态 | 含义 | 进入条件 |
|---|---|---|
| `pending` | 待拆解 | 新任务进入 |
| `planned` | 拆解完成 | 编排层产出时间轴 JSON |
| `executing` | 执行中 | 有事件被调度 |
| `checking` | 机检中 | 执行层回吐产物 |
| `redoing` | 重做中 | 机检不通过 / 人审驳回 |
| `reviewing` | 人审中 | 机检全过 |
| `done` | 完成 | 人审批准 |
| `stuck` | 卡死上报 | 重做预算耗尽 |

### 1.2 两条硬规则

1. **重做预算**：每个事件默认 **3 次**（可配置）。预算耗尽 → `stuck`，该事件标"人工接管"，其余照常推进。
2. **异步回填**：生成型事件（illustration / anim）先 `pending` 占位，生成完成回填 `ready`，合成最后统一跑。

## 2. 编排层（任务拆解）

### 2.1 输入 / 输出

- 输入：原始视频 + 用户需求 + 转录文本（ASR，带时间戳）
- 输出：一份 `timeline.json` + 步骤状态报告

### 2.2 步骤序列

1. **粗剪**：调用剪辑执行器（自建管线，见第 3 章），产出剪辑视频 + 剪辑决策记录（cut-list）
2. **转录对齐**：转录文本按句/词对齐到剪辑后时间轴（词级时间戳保留）
3. **内容分析**：LLM 把内容切成"讲解要点"，每个要点 = 一个语义组（主题/画面区域/关键句/关键词）
4. **动效事件决策**：按"信号 → 事件"规则为每个要点生成事件，写入时间轴 JSON（**事件锚到语义锚点**）
5. **调度**：交内核执行

### 2.3 时间轴 JSON Schema v0.2（修订：词级时间戳 + 语义锚点）

```json
{
  "version": "0.2",
  "fps": 30,
  "duration": 37.4,
  "source": {"video": "粗剪.mp4", "transcript": "transcript.json"},
  "segments": [
    {
      "id": "s1",
      "start": 0.0, "end": 12.3,
      "text": "黑洞的事件视界，是光线有去无回的边界。",
      "words": [
        {"w": "黑洞", "start": 0.0, "end": 0.6},
        {"w": "的", "start": 0.6, "end": 0.75},
        {"w": "事件视界", "start": 0.75, "end": 1.8}
      ]
    }
  ],
  "groups": [
    {"id": "g1", "topic": "事件视界", "anchor_segment": "s1", "anchor_word": "事件视界", "events": ["e01", "e02"]}
  ],
  "events": [
    {
      "id": "e01",
      "group": "g1",
      "type": "overlay",
      "state": "ready",
      "anchor": {"segment": "s1", "word": "事件视界"},
      "start": 0.8, "end": 3.0,
      "target": "circle",
      "anchor_xy": {"x": 0.62, "y": 0.35},
      "params": {"color": "#ffd100", "label": "光线有去无回", "fade": [0.2, 0.4]},
      "retries": 0,
      "check": {"status": "pending"}
    }
  ]
}
```

**字段表（v0.2 修订重点）**

| 字段 | 说明 | 必填 |
|---|---|---|
| `segments[].words[]` | **词级时间戳**：`{w, start, end}`——社区共识：句级插值会导致字幕漂移，词级是 2026 标配 | 是 |
| `anchor` | **语义锚点（主键）**：`{segment, word}` 锚到某句某词；重剪后由锚点重算秒数 | 是 |
| `start / end` | **派生秒（缓存）**：由语义锚点 + 剪辑映射表重算；不直接作为人审/重做的主键 | 是（每次渲染前重算） |
| `anchor_xy` | 画面归一化坐标（0~1），"指向哪里"的答案 | 按类型 |
| 其余 | 继承 v0.1：type / group / state / params / retries / check | — |

> **锚定原则（v0.2 核心）**：语义锚点是主键，绝对秒是派生缓存。任何剪辑/重剪只重算派生秒，不动锚点——这是"人审驳回重做不崩"的根基（对齐 ossclip `overrides.json` 锚定词的设计）。

### 2.4 信号 → 事件决策规则（v0.1 继承）

| 内容信号（LLM 识别） | 触发事件 | 所需输入 |
|---|---|---|
| 语音方位词（"这个区域""右侧"） | `overlay: arrow / circle` | 画面坐标（需锚点检测） |
| 概念首次定义 | `overlay: callout` + `card` | 文案 + 位置 |
| 关键数字 / 结论句 | `overlay: word_highlight` | 字幕时间轴（词级） |
| 抽象概念难理解 | `illustration` | prompt |
| 逻辑关系复杂 | `diagram` | 节点列表 |
| 大家没见过的东西 | `anim` | prompt + 时长 |
| 提问 / 转折 | `overlay: zoom / mask` | 无 |

## 3. 执行层（工具运用）

### 3.1 执行器统一接口契约（v0.1 继承）

```json
{ "op": "render", "event": { "...": "事件字段" } }
→
{ "asset": "assets/e01.svg", "meta": { "actual_duration": 2.2, "anchor": {...}, "summary": "...", "status": "ok" } }
```

### 3.2 剪辑执行器 · 操作层设计（v0.2 新增，本版本核心）

> 定位：自建管线（社区调研结论：转录驱动剪辑是绝对主流，SaaS/NLE 不可编程，只能自建）。

#### 3.2.1 数据流（脚本剪辑原理）

```
raw.mp4
  ↓ 索引层：faster-whisper 词级转录 + ffmpeg 音量/静音分析
transcript.json（词级时间戳） + silence-map
  ↓ 决策层：剪辑规则 + LLM + 人编辑文本（AutoCut 模式）
cut-list.json [{start, end, reason, confidence}]
  ↓ 执行层：ffmpeg 抽段（re-encode）→ concat 拼接
粗剪.mp4 + 字幕重映射（外部标记重映射，见 3.2.4）
  ↓ 产物层
timeline_base.json（镜头节点 + 词级字幕节点，供动效编排）
```

#### 3.2.2 命令规范（Windows 可执行）

```powershell
# ① 转录（词级时间戳必须）
faster-whisper raw.mp4 --model medium --language zh --word_timestamps True
# → transcript.json（segments 含 words[]）

# ② 抽段（每个保留区间 re-encode，帧精确；禁止 -c copy）
ffmpeg -ss 0.0 -to 12.3 -i raw.mp4 -c:v libx264 -c:a aac seg_01.mp4

# ③ 拼接（各段已统一参数，可 -c copy）
ffmpeg -f concat -safe 0 -i list.txt -c copy 粗剪.mp4

# ④ 抽帧预览/机检（不预览画面，按需抽帧）
ffmpeg -ss 8.0 -i 粗剪.mp4 -frames:v 1 frame_08s.png
```

#### 3.2.3 剪辑规则表（参数，社区验证基线）

| 规则 | 参数（默认） | 说明 |
|---|---|---|
| 静音检测 | VAD min-silence 500ms；删除静音段 ≥ 1.5s | 对应 GUI 波形里的死寂 |
| 废话词删除 | 中文：嗯/啊/那个/然后；英文：um/uh/like/you know | 词级时间戳定位，从 cut-list 排除 |
| 口误/重复 | LLM 分析 false starts / 语义重复句 | 决策层 AI 兜底 |
| 最短保留区间 | ≥ 0.5s | 防碎剪 |
| 比特率 | `--bitrate 10m`（AutoCut 默认基线） | 可调 |
| 压缩静音 | 静音 ≥0.8s 压缩至 0.2s（可选，SnapFlow 类） | 保节奏 |

#### 3.2.4 cut-list 与字幕重映射

```json
// cut-list.json（剪辑决策记录，留痕）
[{ "start": 0.0, "end": 12.3, "reason": "保留-讲解主段" },
 { "start": 12.3, "end": 15.1, "reason": "静音2.8s" },
 { "start": 15.1, "end": 40.2, "reason": "保留" }]
```

- 重映射规则：新字幕秒 = 原秒 − 前面被删总时长；词级锚点不参与重算（锚点恒定）。
- 机检（本环节）：ffprobe 验证时长 > 0、无空段、音频不过载、字幕时间轴连续。

### 3.3 执行器清单与选型（v0.2 更新：粗剪执行器定位自建）

| 执行器 | 吃的事件 | 产物 | 选型（默认） | 替换候选 |
|---|---|---|---|---|
| **剪辑执行器** | 整个任务 | 粗剪.mp4 + cut-list + timeline_base | **自建**（faster-whisper + 规则脚本 + ffmpeg，见 3.2） | AutoCut 式开源管线 |
| overlay 渲染器 | `overlay` | SVG/PNG 图层 | **自建**（浏览器 SVG 渲染 + ffmpeg） | 剪映标注模板 |
| card 渲染器 | `card` | 关键词卡图层 | 自建 / Remotion | 剪映花字 |
| diagram 生成器 | `diagram` | 结构图 | 现成图表库（mermaid 等） | 自建 |
| illustration 生成器 | `illustration` | 图片 | 现成文生图服务 | 素材库 |
| anim 生成器 | `anim` | 视频片段 | 现成文生视频 + motion-reel | 3D / AE |

## 4. 机检层（Agent 自检 · 保基础质量）

### 4.1 定位（v0.1 继承）

只查"硬"指标，不判审美；边界宁可窄，漏检由人审兜底。

### 4.2 检查项清单（v0.2 增补剪辑环节 + 词级校验）

| 对象 | 检查项 | 判定方式 |
|---|---|---|
| 粗剪 | 时长 > 0；无空段；音频不过载；字幕时间轴连续 | ffprobe / 规则 |
| 转录 | 词级时间戳完整（words[] 非空）；句间无大段缺失 | 规则 |
| 全局 | 事件不越界；id 不重复；group 引用有效；**语义锚点指向存在的 segment/word** | 规则 |
| `overlay` | 锚点坐标 0~1；起止合法；无同层重叠冲突 | 规则 |
| `card` | 文字非空；时长 ≥ 阈值 | 规则 |
| `diagram` | 节点非空；结构合法 | 规则 |
| `illustration / anim` | 生成成功；实际时长匹配；内容摘要与语音关键词一致（LLM 比对）；编码有效 | 工具 + LLM |
| 输出 | 成片可播放（ffprobe / verify） | 工具 |

### 4.3 判定逻辑（v0.1 继承）

全过 → 交人审；任一失败且预算未耗尽 → 只重做该事件；预算耗尽 → stuck 人工接管。

---

## 5. 审核层（人 · 查验校准，不制作）

### 5.1 定位（v0.1 继承）

人不制作，只做最终校准；目标 30 秒完成一次校准。

### 5.2 人审工作台（v0.2 增补：映射 ossclip report.txt / overrides.json）

| 给人看什么 | 对应产物 | 操作 |
|---|---|---|
| 事件列表 + **每步"做了什么、为什么"**（report.txt 模式） | `review_manifest.json` | 批准 / 驳回+原因 / 改参数 |
| 关键帧 + 单事件产物 | assets/ 抽帧 | 同上 |
| 粗成片（可选播放） | 粗剪.mp4 | 整体观感兜底 |
| **人审改动锚定在词上**（overrides.json 模式） | `overrides.json` | 改动随词走，重剪/重跑不丢 |

### 5.3 与机检的边界（v0.1 继承）

机检保"没做错"；人审判"做得好不好"；驳回 → redoing；预算耗尽 → stuck 人工接管。

## 6. 数据流与产物清单（v0.2 更新）

**数据流**：原始视频 → 剪辑执行器（转录→cut-list→ffmpeg→粗剪+timeline_base）→ 编排层（内容分析→事件决策，锚语义）→ 时间轴 JSON → 多执行器 → 机检 → 人审 → 合成出片

**产物清单**

| 产物 | 路径 | 说明 |
|---|---|---|
| 时间轴 JSON | `timeline.json` | 语义锚点主键 + 派生秒；全流程契约 |
| 剪辑决策 | `cut-list.json` | 每个区间的保留/删除 + reason（留痕） |
| 图层/图片/片段 | `assets/` | 各执行器产物 |
| 校验清单 | `review_manifest.json` | 机检结果 + 人审结论 + **每步理由**（report.txt 映射） |
| 人审改动 | `overrides.json` | 锚定词级，重跑不丢（overrides.json 映射） |
| 成片 | `final.mp4` | 最终交付 |

## 附录 B：社区调研结论（v0.2 新增，已吸收）

- 转录驱动剪辑是绝对主流（Descript 2017 开创 → AutoCut 2022 开源 → 2026 agent skill/本地 CLI 爆发）
- 2026 标配：词级时间戳、re-encode 强制、LLM 参与剪辑决策、本地优先
- 关键参考：ossclip（本地 CLI 一条龙 + LLM 规划图形 + report.txt/overrides.json）、AutoCut（文本编辑粗剪）、video-subtitle-cutter（agent skill 形态）、videocut:narration-cut（词级 + 人审页）
- 载体结论：SaaS（Descript）与专业 NLE（DaVinci/Premiere）不可编程，不能做执行器；执行器必须是 CLI/脚本
